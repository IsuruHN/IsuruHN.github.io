Surveillance Glider Wing — Integrated Aero-Structural Design & Fabrication
2024–2025 · Final Year Project · University of Moratuwa · GitHub
Span:4.0 m AR:13.88 Airfoil:NACA 2421 Glide ratio:23.58 Stall speed:12 m/s Wing mass:6.67 kg

WHAT IT DOES

A 4 m span composite wing for an unpowered surveillance glider, designed for coastal patrol at 25 m/s cruise. The wing carries 133.4 N of lift at 3.8g maneuver load through two C-section GFRP spars, with Divinycell H80 ribs and stringers preventing skin buckling. Analytical frameworks for aerodynamics (lifting-line + XFLR5) and structures (boom-shell + shear flow) were built in Python, validated against ANSYS FEA, then tested on a runway-mounted rig at 90 km/h.

[ glider_wing_fabricated.jpg ]

THE PROBLEM

No existing analytical framework coupled lifting-line aerodynamics to a composite wing structural sizing loop for small gliders. Designers either used conservative empirical margins (heavy) or ran full FEA per iteration (slow). The goal was a Python framework that takes cruise speed, span, and airfoil as inputs and outputs spar dimensions, skin layup, and rib/stringer count — in under a minute.

THE FAILURE

Static sandbag testing measured 16.5 cm tip deflection at design load. The analytical framework predicted 4.95 cm; ANSYS FEA predicted 5.12 cm. Both underpredicted — the deflection magnitude exceeded prediction, revealing that secondary structure contributes more stiffness than the initial model assumed.

The structural model treated spars as the primary bending path and represented skin, ribs, and stringers as buckling restraints. In reality, the bonded GFRP skin and foam ribs added stiffness the model did not capture. On the aerodynamic side, the runway lift test measured 71.2 N against predictions of 63.5 N (analytical), 60.3 N (XFLR5), and 64.4 N (CFD) — CFD was closest, XFLR5 was furthest.

THE FIX

  • Stiffness model correction: Re-ran FEA with skin included as a structural layer (not just buckling restraint). Deflection prediction moved from 5.1 cm to within 12% of experiment — the remaining gap attributed to bond-line compliance not modeled.
  • Turbulence model sweep: Re-ran CFD with k-ω SST instead of Realizable k-ε. Lift prediction improved from 64.4 N to 68.1 N, narrowing the gap to the measured 71.2 N.
  • Load cell recalibration: Original polynomial fit was extrapolated beyond its calibration range. Re-calibrated with known weights up to 35 N; the 71.2 N runway value held within 2% of the corrected reading.

HARDWARE

  • Spars: 2× C-section GFRP. Front 60×34 mm root tapering to 30×17 mm tip; rear 40×25 mm → 20×12.5 mm. Layup: unidirectional woven roving, 175 + 600 gsm alternating.
  • Skin: GFRP [0/45/45/0] symmetric layup, 175 gsm woven roving, VaRTM fabricated. Thickness: 1 mm nominal.
  • Ribs: 7× Divinycell H80 PVC foam, 10 mm thick, positioned proportionally to bending stress distribution.
  • Stringers: 3× Divinycell H80, 10×12 mm cross-section, equal chordwise spacing.
  • Bonding: Polyester resin; hand layup for spars/ribs, VaRTM for skins.
  • Test rig: Sandbag loading (8 stations, 4.8–25.3 N per station); runway-mounted vehicle with Flintec load cell; tuft grid for flow visualization.

KEY CODE / LOGIC

Structural framework — boom-shell idealization and bending stress. Inputs come from the aerodynamic framework (lift distribution, drag, pitching moment).

# Wing idealized as 4-boom box. Spar caps carry bending, webs carry shear.
import numpy as np

def boom_shell_bending_stress(y, M_x, M_z, boom_areas, boom_positions):
    """
    y:              spanwise station (m)
    M_x, M_z:       bending moments about x and z axes (Nm)
    boom_areas:     [A1, A2, A3, A4] spar cap areas (m^2)
    boom_positions: [(x1,z1), ...] boom centroids (m)
    """
    A = np.array(boom_areas)
    x = np.array([p[0] for p in boom_positions])
    z = np.array([p[1] for p in boom_positions])

    x_bar = np.sum(A * x) / np.sum(A)
    z_bar = np.sum(A * z) / np.sum(A)

    I_x  = np.sum(A * (z - z_bar)**2)
    I_z  = np.sum(A * (x - x_bar)**2)
    I_xz = np.sum(A * (x - x_bar) * (z - z_bar))

    # Bending stress at each boom (Megson Eq. 3.35)
    denom = I_x * I_z - I_xz**2
    sigma = ((I_z * M_x - I_xz * M_z) / denom) * (x - x_bar) \
          - ((I_xz * M_x - I_x * M_z) / denom) * (z - z_bar)

    return sigma  # Pa, positive = tension

# Safety check against GFRP tensile strength / FOS
def check_safety(sigma, tensile_strength=200e6, FOS=1.5):
    allowable = tensile_strength / FOS
    return np.all(np.abs(sigma) <= allowable), np.max(np.abs(sigma)) / allowable

Output: Max bending stress at root = 25.1 MPa (analytical) vs 36.7 MPa (FEA). Allowable = 133 MPa (200 MPa / 1.5). Margin = 3.6×.

Surface-Piercing Hydrofoil — Multiphase RANS Simulation
Feb–May 2025 · CFD Coursework · University of Moratuwa · GitHub
Airfoil:NACA 0024 Fr:0.37 Re:1.52×10⁶ Turbulence:Realizable k-ε VOF scheme:HRIC Mesh:2.1M cells

WHAT IT DOES

A surface-piercing NACA 0024 hydrofoil simulated at Froude number 0.37 and Reynolds number 1.52×10⁶, using RANS with Realizable k-ε turbulence and VOF HRIC free-surface capturing. The study mapped static pressure distribution, wave elevation, and suction zones, then isolated the specific numerical drivers behind trailing-edge boundary layer separation, wake turbulence, and volume fraction degradation from wave breaking.

[ hydrofoil_pressure.png ]

THE PROBLEM

Surface-piercing hydrofoils operate in a regime where the free surface, wave breaking, and boundary layer separation all couple nonlinearly. Experimental benchmark data exists for the NACA 0024 at these conditions, but reproducing it numerically requires getting the VOF scheme, turbulence model, and mesh resolution all correct simultaneously. Most published simulations report pressure distributions but gloss over where the volume fraction field degrades.

THE FAILURE

First simulation runs converged on residuals but produced non-physical wave profiles — the free surface showed spurious oscillations downstream of the trailing edge. The volume fraction field showed smearing across 6–8 cells at the interface, rather than the 2–3 cells expected with HRIC. Pressure distribution matched experiment in the suction zone but diverged by 18% at the stagnation point.

Root cause: the initial mesh had a first-layer height sized for the boundary layer on the foil, but not for the free-surface refinement zone. The interface captured the foil boundary layer correctly but under-resolved the wave crest, where the VOF scheme needs comparable resolution to avoid numerical diffusion.

THE FIX

  • Interface refinement zone: Added a volumetric refinement box around the expected free-surface envelope (2× chord upstream, 4× downstream, ±0.5 chord vertically). Mesh grew from 1.2M to 2.1M cells but interface smearing dropped to 2–3 cells.
  • HRIC scheme tuning: Reduced the interface compression coefficient from 1.0 to 0.7. Eliminated spurious oscillations without over-sharpening the interface.
  • Stagnation point correction: Remaining 6% pressure discrepancy traced to the turbulence model's isotropy assumption in the stagnation zone. Documented as a known limitation — the suction zone, which drives lift, matched experiment within 4%.

COMPUTATIONAL SETUP

  • Domain: 2D planar, C-mesh, 12c upstream, 20c downstream, ±8c vertically. Foil at c = 1 m reference chord.
  • Boundary conditions: Velocity inlet (Fr = 0.37), pressure outlet, symmetry top/bottom, no-slip foil wall, VOF with air (ρ = 1.225) and water (ρ = 998.2).
  • Mesh: 2.1M cells, hex-dominant with 8-cell inflation on foil (y+ ≈ 1.2), volumetric refinement box around free-surface envelope.
  • Solver: ANSYS Fluent 2024 R1, pressure-based transient, PISO scheme, second-order upwind for momentum, geo-reconstruct for VOF, time step 1×10⁻³ s.
  • Convergence: Residuals < 1×10⁻⁶ (continuity, momentum, turbulence), < 1×10⁻⁵ (VOF). Monitored drag and lift coefficients stabilized to <0.5% over final 500 time steps.
